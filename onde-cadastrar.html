Onde cadastrar em cada plataforma

Veja o caminho exato nos menus do RBX ISP, IXC Soft, SGP, HubSoft e MK-AUTH para configurar o gateway, colar o código de disparo gerado e ativar o envio automático.

Sistema:

RBX ISP (RouterBox)

RBX ISP
|VARIAVEL|
Caminho do template e disparo
Empresa → Parâmetros → Central de Notificações
  1. Cadastre ou confira a integração do gateway em Empresa → Parâmetros → Integrações → SMS.
  2. Acesse Empresa → Parâmetros → Central de Notificações e edite a regra de cobrança/aviso desejada.
  3. Na seção Envio de aviso por sms, escolha a frequência em Enviar e selecione o gateway em Gateway para envio de SMS.
  4. Cole o código gerado na aba Código de disparo dentro do campo Conteúdo do SMS *.
  5. Em Destinatário(s) *, marque Cadastro geral e os contatos adicionais necessários.
Atenção no RBX: use ||| após variáveis terminadas em | e confira no ícone ? se o Tipo de Envio por Documento (Agrupado vs Simples) libera variáveis de boleto/Pix.
Delimitador: |VARIAVEL| Gerar código para RBX →

IXC Soft (IXC Provedor)

IXC Soft
#variavel#
Caminho do template
Sistema → CRM → Mensagens → Mensagem SMS
  1. Acesse Sistema → CRM → Mensagens → Mensagem SMS e clique em Novo.
  2. Preencha a descrição do modelo e cole o código gerado no corpo da mensagem (usando variáveis #...#).
  3. Para automatizar o disparo na cobrança, vá em Sistema → CRM → Parâmetros → Parâmetros da Cobrança (ou na Régua de Cobrança, conforme a versão).
  4. Vincule a mensagem cadastrada aos gatilhos de dias antes ou depois do vencimento.
Dica: na tela de edição da mensagem no IXC existe o botão Variáveis para conferir todas as tags habilitadas na sua versão.
Delimitador: #variavel# Gerar código para IXC →

SGP (TSMX)

SGP
{variavel}
Caminho do template e disparo
Sistema → Avisos SMS
  1. Se o gateway ainda não estiver configurado, cadastre em Sistema → Gateway SMS (ou Sistema → Configuração → Gateways).
  2. Acesse Sistema → Avisos SMS e clique em Novo.
  3. Informe a Descrição (ex.: Aviso de vencimento) e selecione o Gateway SMS configurado.
  4. Defina o campo Dias (ex.: -3 para 3 dias antes do vencimento, ou número positivo para pós-vencimento).
  5. Cole o código gerado no campo Mensagem e salve.
Dica para PDF: caso utilize a variável {link} no SGP, confirme se a variável global SMS_FATURA_URL está preenchida nas configurações do sistema.
Delimitador: {variavel} Gerar código para SGP →

HubSoft

HubSoft
[[variavel]]
Cadastro do layout e regra de disparo
Configuração → Geral → Layout de SMS  |  Financeiro → Forma de Cobrança
  1. Vá em Configuração → Geral → Layout de SMS e clique no botão + (Adicionar).
  2. Defina a descrição, selecione a integração/mensageiro, escolha o Tipo (ex.: Carnê Bancário) e cole o código gerado no texto.
  3. Para configurar quando enviar, acesse Configuração → Financeiro → Forma de Cobrança.
  4. Clique em Ações → Editar na forma de cobrança desejada, abra a aba SMS e clique em Adicionar para vincular os dias e o layout criado.
  5. Confirme se a rotina de disparo automático está ativa em Configuração → Geral → Rotinas.
Atenção: sem a rotina de envio de SMS ativa em Configuração → Geral → Rotinas, os avisos configurados na Forma de Cobrança não disparam automaticamente.
Delimitador: [[variavel]] Gerar código para HubSoft →

MK-AUTH

MK-AUTH
%variavel%
Caminho do gateway e mensagens
Opções → Configurar SMS (ou Servidor de SMS)
  1. No menu principal do MK-AUTH, acesse Opções → Configurar SMS (ou Servidor de SMS, conforme a versão).
  2. Na aba Servidor / Gateway, configure os dados de envio do gateway integrado.
  3. Abra a aba Mensagens e cole o código gerado nos campos de cobrança/aviso de vencimento desejados.
  4. No cadastro de cada cliente (aba Financeiro), certifique-se de que a opção Recebe SMS está marcada.
Atenção no PDF do MK-AUTH: o MK-AUTH não possui variável pronta de link curto; substitua SEU-PROVEDOR na URL do campo header_link pelo domínio real do seu servidor.
Delimitador: %variavel% Gerar código para MK-AUTH →
