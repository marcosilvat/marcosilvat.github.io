Como cadastrar uma campanha e disparo em massa

Passo a passo para segmentar o público, cadastrar a mensagem e disparar campanhas pontuais ou recorrentes no SGP, IXC Soft, HubSoft e RBX ISP.

Sistema:

SGP (TSMX)

SGP
{variavel}
Caminho da campanha em lote / recorrente
Sistema → Ferramentas → SMS em Lote  |  Sistema → Avisos SMS
Campanha pontual (envio em lote)
  1. Com o gateway configurado e com saldo, acesse Sistema → Ferramentas → SMS em Lote.
  2. Aplique os filtros de segmentação (bairro, plano, status do contrato, faixa de vencimento etc.) para definir quem receberá a campanha.
  3. Selecione o Gateway SMS, escreva ou cole a mensagem da campanha ({variavel}) e execute o disparo do lote.
  4. Para campanhas recorrentes de cobrança/aviso, use Sistema → Avisos SMS → Novo definindo Dias, Status Contrato, Dias da semana e intervalo entre envios.
  5. Acompanhe entregas, aceitação e eventuais falhas em Sistema → Histórico SMS.
Importante no SGP: a tela Sistema → SMS faz envio manual avulso; para campanhas em massa use SMS em Lote, e lembre de configurar SMS_FATURA_URL se enviar {link}.

IXC Soft (IXC Provedor)

IXC Soft
#variavel#
Caminho do modelo e disparo em massa
Sistema → CRM → Mensagens → Mensagem SMS  |  Relatórios → CRM
Etapas para montar e disparar a campanha
  1. Cadastre o texto em Sistema → CRM → Mensagens → Mensagem SMS → Novo escolhendo o Gateway / Provedor, Remetente e a Mensagem (#variavel#), depois clique em Salvar.
  2. Segmente o público em Relatórios → Relatórios Provedor → Relatórios Contratos → Relatório Contratos (ou relatórios de Clientes/Leads).
  3. Aplique os filtros desejados (status ativo/bloqueado/inadimplente, cidade, bairro, plano ou vencimento) e clique em Detalhados → Detalhado.
  4. Na tela da listagem filtrada, clique na ação/integração CRM.
  5. No campo Mensagem SMS, clique na Lupa, selecione a mensagem criada, faça um envio de teste para seu número e dispare o lote.
Dica para WhatsApp / Opa! Suite: no ecossistema IXC, disparos em massa via API oficial utilizam modelos aprovados na Meta com tags e controle de intervalo entre envios.

HubSoft

HubSoft
[[variavel]]
Caminho da campanha em lote
Configuração → Geral → Layout de SMS  |  Relatórios → Serviços do Cliente
Passo a passo para campanha e avisos em massa
  1. Confirme o gateway ativo em Configuração → Integrações → SMS/Mensageiros.
  2. Em Configuração → Geral → Layout de SMS → (+), crie o modelo: para campanhas gerais/comunicados escolha o Tipo: Cliente; para cobrança, use Carnê Bancário.
  3. Para disparar ao público filtrado, acesse Relatórios → Serviços do Cliente, aplique os filtros (bairro, cidade, plano, status) e carregue a lista.
  4. Marque a caixa de seleção no topo da tabela (ou os clientes desejados), clique em Ações e selecione o disparo em massa/notificação personalizada.
  5. Escolha o layout cadastrado no passo 2, confira data/hora e confirme o envio (ou use Grupos de Notificação para campanhas recorrentes como aniversariantes).
Atenção às variáveis: cada Tipo de Layout de SMS aceita apenas as variáveis daquele contexto. Se alguma tag aparecer sem converter no teste, confira se o Tipo selecionado é compatível.

RBX ISP (RouterBox)

RBX ISP
|VARIAVEL|
Caminho de regras, régua e disparo
Empresa → Parâmetros → Central de Notificações  |  Cobrador Virtual
Como estruturar campanhas no RBX
  1. Verifique o provedor de SMS em Empresa → Parâmetros → Integrações → SMS com URL/usuário/chave válidos e saldo ativo.
  2. Para campanhas automáticas por evento (vencimento, cobrança, bloqueio, faturamento), acesse Empresa → Parâmetros → Central de Notificações → Novo.
  3. Defina a Categoria do evento, marque o envio por SMS, escolha o gateway, cole o template (|VARIAVEL|) e salve.
  4. Para campanhas de régua de cobrança com controle de janela de horários, configure também as regras do Cobrador Virtual.
  5. Para campanhas pontuais de marketing/manutenção (fora de eventos), segmente a base nos relatórios de clientes/contratos do RBX, exporte os contatos em CSV para disparar no painel do gateway contratado (ou integre via Web Service ws_json.php / send_sms).
Dica de entrega: valide se os cadastros no RBX estão com DDD + 9º dígito corretos e revise as diretrizes de opt-out/LGPD em campanhas promocionais.
